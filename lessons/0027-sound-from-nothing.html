The Game Finds Its Voice: Autoloads & Sound

Twenty-six lessons of total silence. Today the forest gets wind and birdsong, the wolves growl and yelp, and every swing of the sword sounds like something — all routed through one tiny global script, built on a Godot concept you haven't met yet: the autoload.

TODAY

One 40-line script, registered once, and any script in the game can say Sfx.play("hit") — no paths, no setup. Eleven one-shot sounds (swings, bites, a pickup chime, a death sting) plus a looping forest ambience, and a campfire you can hear getting closer.

The problem: who owns a sound?

Sound has a property nothing else in your game has had: it must outlive the thing that made it. When a wolf dies, the wolf node is freed — but its death yelp has barely started. If the AudioStreamPlayer lived inside wolf.tscn, the yelp would be cut off mid-cry, every time. And everything wants to make noise: the player swings, the wolf bites, the sword pickup chimes, the HUD pings. Scatter players through every scene and you'll wire the same nodes a dozen times.

What we want is a sound bus: one script, alive for the whole game, that anyone can call.

autoload

A script (or scene) Godot instances once, at the top of the scene tree — a child of /root, above your current scene — before your main scene loads. You give it a name — ours is Sfx — and from then on every script in the project can use that name directly. No get_node(), no paths. Other engines call this a singleton.

AudioStreamPlayer

The node that plays a sound. Plain AudioStreamPlayer plays at full volume everywhere; AudioStreamPlayer2D sits at a position in the world and gets quieter with distance.

volume_db

Loudness in decibels — a relative scale where 0 is "as authored", -6 is roughly half as loud, -12 half of that. Mixing a game is mostly choosing these numbers.

pitch_scale

Playback speed/pitch multiplier. 1.0 is normal. A few percent of random variation makes a repeated sound feel performed instead of stamped.

Part A — the bus: sfx.gd

Create sfx.gd in the project root (next to player.gd). It extends plain Node — it has no body, no position; it's pure behaviour:

GDScript · sfx.gd
extends Node

## Tiny SFX bus (autoload "Sfx"). One-shot players that free themselves;
## slight pitch jitter keeps repeated sounds from feeling stamped.

const STREAMS = {
    "swing": preload("res://assets/sounds/swing_whoosh.wav"),
    "miss": preload("res://assets/sounds/swing_miss.wav"),
    "hit": preload("res://assets/sounds/hit_flesh.wav"),
    "crit": preload("res://assets/sounds/hit_crit.wav"),
    "hurt": preload("res://assets/sounds/hurt_player.wav"),
    "growl": preload("res://assets/sounds/wolf_growl.wav"),
    "bite": preload("res://assets/sounds/wolf_bite.wav"),
    "yelp": preload("res://assets/sounds/wolf_yelp.wav"),
    "pickup": preload("res://assets/sounds/pickup_chime.wav"),
    "ping": preload("res://assets/sounds/target_ping.wav"),
    "death": preload("res://assets/sounds/death_sting.wav"),
}

func play(key: String, volume_db: float = 0.0, pitch_jitter: float = 0.06):
    var p := AudioStreamPlayer.new()
    p.stream = STREAMS[key]
    p.volume_db = volume_db
    p.pitch_scale = 1.0 + randf_range(-pitch_jitter, pitch_jitter)
    add_child(p)
    p.finished.connect(p.queue_free)
    p.play()
The dictionary is the menu. Every sound gets a short name; callers say Sfx.play("crit") and never touch a file path. Add a sound to the game = add one line here.
The parameter is key, not name — same discipline as Lesson 26's map_seed: every Node already has a name property, and shadowing a built-in earns you a warning and future confusion.
p.finished.connect(p.queue_free) — a signal connected in code. In Lesson 8 you wired body_entered with the editor's Signals tab; this is the same wire made by hand: when this player finishes, delete it. The bus never accumulates dead nodes — every sound cleans up after itself.
The pitch jitter (±6%) is the whole difference between "a sword sound" and "a sound effect on a loop." Identical samples back-to-back scream machine; tiny random variation reads as performance. Set the default to 0.0 once, swing at a wolf for ten seconds, and you'll never remove it again.

Part B — register it as an autoload

1

Open Project → Project Settings, switch to the Globals tab (it hosts Autoload).

2

Click the folder icon next to Path, choose res://sfx.gd. The Node Name auto-fills as Sfx — keep it.

3

Click Add. It appears in the list with its checkbox ticked.

That's it. Behind the scenes this wrote one line into project.godot:

INI · project.godot
[autoload]

Sfx="*res://sfx.gd"
The * prefix is the ticked checkbox: it registers Sfx as a global name every script can use directly. Untick it and Godot still instances the node at startup — you'd just have to reach it the long way, get_node("/root/Sfx"), instead of by bare name.
◈ THE AUTOLOAD LIVES ABOVE THE WORLD

When you die, the game calls reload_current_scene() — the whole forest, wolves and all, is torn down and rebuilt. The death sting doesn't care: play() parents its sound to the bus itself, not to the scene, so even a reload landing mid-note couldn't cut it short. Things that must survive the world ending belong in an autoload.

Part C — sounds that live somewhere: play_at()

A growl shouldn't be the same volume from across the map. For sounds that belong to a place, the bus has a second function using the positional player:

GDScript · sfx.gd
# Positional one-shot (falls off with distance from the camera/player).
func play_at(key: String, pos: Vector2, volume_db: float = 0.0):
    var p := AudioStreamPlayer2D.new()
    p.stream = STREAMS[key]
    p.volume_db = volume_db
    p.max_distance = 420.0
    p.pitch_scale = 1.0 + randf_range(-0.06, 0.06)
    get_tree().current_scene.add_child(p)
    p.global_position = pos
    p.finished.connect(p.queue_free)
    p.play()
max_distance = 420.0 — beyond ~420 pixels the sound is inaudible; inside that it swells as you approach. A growl at the edge of hearing is information: something noticed you.
Why current_scene.add_child this time? Ownership. A growl belongs to a place in the world — if the world is torn down (death → reload), the growl should die with it, not haunt the respawn. Parenting it into the scene buys exactly that, and keeps the always-alive bus free of world-bound children. The two functions are a matched pair: play() = sounds that belong to the game, play_at() = sounds that belong to a place.

Part D — mixing: the loudness ladder

Now any script can speak. Here's the player's attack table from Lesson 21–24 — listen to the volume_db values, they're doing design work:

GDScript · player.gd — inside attack()
if roll < miss:
    spawn_text_over(t, "Miss", Color.GRAY)
    Sfx.play("miss", -8.0)      # quiet — failure whispers
# … dodge, parry, glancing bands …
elif roll < miss + dodge + parry + glancing + crit:
    var dmg = attack_damage * 2
    t.take_damage(dmg, true)
    # … rage gain (L25) · sparks & camera shake — Lesson 30's story …
    Sfx.play("crit", -2.0)      # loud — triumph shouts
    hit_stop()                  # a heartbeat of frozen time — Lesson 30's story
else:
    t.take_damage(attack_damage)
    # … rage gain (L25) · a small white burst — Lesson 30 …
    Sfx.play("hit", -4.0)       # the everyday thunk

Crit louder than hit, hit louder than miss: outcomes you should celebrate are literally louder than outcomes you should shrug at. The wolf does the same with play_at — growl on aggro (wolf.gd, the Lesson 11 aura), bite on each swing, yelp on death.

TWO SOUNDS REFUSED THE BUS

The forest ambience (wind + birds) and the campfire crackle aren't in STREAMS. They loop forever, so "play once, free on finish" is the wrong lifetime — instead they live as ordinary nodes: an AudioStreamPlayer with Autoplay in main.tscn, and an AudioStreamPlayer2D the forest generator parks at the campfire. Same decision as ever: who owns this thing's lifetime? One-shots own themselves; loops belong to the world that hums them.

◈ WHERE THE WAVS CAME FROM

Every file in assets/sounds/ was synthesized by assets/gen_sfx.py — a detuned three-note sine arpeggio for the chime, shaped noise bursts for hits, filtered wind for ambience — with a fixed random seed, exactly like the forest in Lesson 26: run it again, get the identical sounds. The ambience loops seamlessly because the script builds the noise on a circle (so the end flows into the start) and the WAV import sets loop_mode. You don't need to read it today — but when you want a new sound, it's one function in that file, not a trip to an asset store.
